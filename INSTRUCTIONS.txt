# ANPR (Automatic Number Plate Recognition) System
## Project Instructions & Development Guidelines


# 1. Project Goal

The goal of this project is to build a production-style Automatic Number Plate Recognition (ANPR) system using modern Computer Vision and Deep Learning techniques.

The system should be able to:

1. Detect vehicles from video streams.
2. Track each vehicle with a unique ID.
3. Detect license plates from vehicles.
4. Associate each license plate with the correct vehicle.
5. Extract license plate text using OCR.
6. Store detection information in a database.
7. Provide a clean, scalable, and maintainable software architecture.

The final system should work as a real-world traffic monitoring solution.

---

# 5. Vehicle and Plate Association

The system must determine:

"Which license plate belongs to which vehicle?"


Approach:

1. Detect vehicle bounding boxes.
2. Detect license plate bounding boxes.
3. Compare their positions.
4. Assign plate to vehicle ID.


Matching methods:

- Center point matching
- IoU matching


Example:


```

Vehicle ID: 10

```
    |
    ↓
```

License Plate:
DHAKA-1234

```

# 9. Development Principles


## Clean Architecture

Each module should have only one responsibility.


Example:


Vehicle detector:

Responsible for:

```

Image → Vehicle Detection

```


It should NOT:

- Save database data
- Run OCR
- Handle tracking


---

# 10. Configuration Management

Do not hardcode:

- Model paths
- Confidence values
- Video paths
- Database paths


All configurations should be stored in:


```

config/config.yaml

```


Sensitive values:

```

.env

```


---

# 11. Logging

The system must use logging instead of print statements.


Example:


```

INFO:
Vehicle detector loaded

INFO:
Plate detected

ERROR:
OCR failed

```


Logs location:

```

logs/anpr.log

```


---

# 12. Error Handling

The system should handle:


- Missing model files
- Invalid video input
- Camera failure
- OCR failure
- Database errors


Use custom exceptions.

# 13. Testing
